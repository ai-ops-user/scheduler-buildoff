Marathon M-137 - 4-Party Blind Evaluation

Scheduler Build-Off: the verdict

Two AIs built an operator Scheduler dashboard from an identical spec, blind to each other. Four independent judges - Claude, the OUROBOROS 6-lens board, Codex, and a Cortex doctrine lane - scored both on six criteria (0-10), inspecting the real source. Sites were judged as A and B; the mapping was revealed only after scoring.

Winner: Site A - Claude's build  ·  195–179  ·  3 lanes to 1

Site A swept the three craft-focused judges - including Codex, which built the losing site and still picked A while blind. Cortex's lone dissent for B is principled (see findings).

Key findings

Craft vs. honesty was the real axis. Site A (Claude) won on visual craft, interaction depth, accessibility and polish. Site B (Codex) was cleaner-architected (self-contained CSS, stronger validation, a real edit drawer) and - crucially - honestly surfaced a failed backup that Site A's health summary hid.

Cortex dissented on doctrine, not taste. OUROBOROS observability doctrine says an ops tool must never hide a failure; Site A's fixed-window metric did. That single correctness gap is why Cortex scored B ahead on the axes it has authority over.

The final build takes the best of both: Site A's craft + Site B's honest failure-surfacing + self-contained CSS - plus a non-technical-first redesign with progressive disclosure, tooltips, and a plain-language explainer for every schedule.
